# Movie App

Application web permettant de rechercher, consulter et ajouter des films en favoris grâce à l'API TMDB.

Technologies utilisées :
- React (frontend)
- Vite (outillage et build)
- Tailwind CSS & DaisyUI (design et composants)
- API TMDB (données films)

Fonctionnalités :
- Recherche de films populaires ou par mot-clé
- Affichage des détails d'un film
- Ajout et gestion des favoris
- Pagination

Projet responsive et moderne, idéal pour découvrir React et Tailwind.
